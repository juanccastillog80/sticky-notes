## Agent skills

### Issue tracker

Issues are tracked in GitHub Issues (juanccastillog80/sticky-notes) through the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

Default vocabulary: needs-triage, needs-info, ready-for-agent, ready-for-human, wontfix. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: `GLOSSARY.md` and `docs/adr/` at the repo root. See `docs/agents/domain.md`.

### PR walkthroughs

Every PR must include an interactive walkthrough of its code, linked from the PR body. Don't open a PR without one, and update it whenever the PR's code changes. See `docs/agents/pr-walkthrough.md`.
