Things to try

  1. Grip: under each grip, select a word in a Note, then move the Note. Count the presses each one needs.
  2. Edit entry: under Body, click to edit, click a Note just to bring it to the front. Did it start editing when you didn't want it to?
  3. Hit rule: drag the big L Note so only its corner brushes the Trash zone, with the pointer well away. Compare pointer and overlap.
  4. Raise: drag the back Note across the front one under raise on release. It slides underneath while you drag it.
  5. Resize: shrink a Note from its top-left corner down to the minimum. The bottom-right corner must stay put.
  6. Min size: type three lines into a Note at each minimum. Which minimum still leaves the text readable?
  7. Undo: delete a Note, then undo. Does it come back at the same place and depth?
  8. Scroll: scroll the Board with the wheel while dragging. The Note stays under the pointer (005 scroll compensation).
