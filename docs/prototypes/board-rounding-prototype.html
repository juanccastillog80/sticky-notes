Prototype · throwaway · ticket 004, rounding question

Should a saved Note sit on whole pixels?

The question: while a Note is being dragged or resized, its on-screen position can be fractional (zoomed browser, high-DPI screen, fractional scroll). When the Gesture ends and the Note is saved, should the saved x, y, width, height be rounded to whole CSS pixels? And if so, where does the rounding happen and in what order relative to keeping the Note inside the 1920×1080 Board? Every action below is applied to four copies of the same Note, one per policy, so you can compare them side by side.
