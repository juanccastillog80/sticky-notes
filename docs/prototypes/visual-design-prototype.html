Things to try

  1. Palette: put all six colours side by side (Reset notes). Can you tell each pair apart at a glance? Does any one shout louder than the rest?
  2. Colour choice: create three Notes, recolour one, create another. Did the new Note get the colour you expected?
  3. Picker: recolour a Note under each picker. Count presses, and check that the caret stays where it was.
  4. Board: drag a Note slowly over each Board background. Does the pattern help you line Notes up, or just add noise?
  5. Lift: under each Note style, start a drag. Is it obvious which Note is in your hand, and which Note you're typing in?
  6. Trash zone: under reveal, try to find the Trash zone before your first drag. Under icon, try to hit it.
  7. Type: write a three-line note at the minimum size (140×100) in each font. Which stays readable?
  8. Toolbar: in Full window, compare the top bar and the floating pill with Notes near the top-left of the Board.
